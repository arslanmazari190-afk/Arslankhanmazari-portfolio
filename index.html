I am a dedicated Computer Science student and web developer with a strong focus on crafting responsive user interfaces and automating repetitive browser workflows.

My journey began with mastering core web primitives—semantic HTML5, modern CSS architecture, and Vanilla JavaScript (ES6+). Rather than jumping straight to complex heavy abstractions, I prioritized understanding the DOM, event lifecycles, and asynchronous execution under the hood.
